\subsection{Procedimiento para la Selección de Investigaciones Relevantes}

La selección de investigaciones tomó como referencia el mapeo sistemático de \textcite{petersen2008systematic}, que comprende la formulación de preguntas, búsqueda de estudios primarios, filtrado, clasificación por palabras clave y extracción de información (pp. 2--5). Las preguntas y búsquedas se centraron en gestión del transporte, trazabilidad, seguimiento, geolocalización, optimización de rutas y plataformas web para procesos logísticos.

Se incluyeron artículos científicos y trabajos académicos pertinentes para estos temas y los objetivos del proyecto. Se excluyeron duplicados, documentos con menciones superficiales y materiales sin aportes relevantes. Cuando el resumen resultó insuficiente para valorar su pertinencia, se revisaron la introducción o las conclusiones, conforme a la recomendación de los autores.

Los estudios seleccionados se agruparon por palabras clave en categorías de gestión logística, seguimiento y geolocalización, optimización de rutas, sistemas de gestión de transporte, plataformas SaaS y tecnologías de desarrollo web.

Una vez establecido el procedimiento seguido para identificar y organizar las investigaciones relevantes, resulta necesario ordenar las actividades realizadas y pendientes dentro del desarrollo del proyecto. Para ello, el cronograma presenta las principales etapas de trabajo y el período correspondiente a cada una.
